# Components (Flow Design System — synced with Figma 1 Oct 2026)

Source of truth: Figma file `NQpg4P9K158sjcEKmMLd8w`. Components are filed by page: **Components** (node `723:6170`) holds the shared building blocks any screen may use; pages starting with `↪ ` hold pieces used only by one product or feature — **↪ Urbanflow** (`6047:1812`, the modelling workspace), **↪ Compliance**, **↪ Comments**, **↪ Files** (↪ Proposals is empty — its parts moved to **Shell**, page `6077:605`, the shared app chrome). Use a `↪` component only for its feature; elsewhere compose from Components and flag it.

The same components run as React in the Flow artifact (https://claude.ai/artifact/6tDZ6LvaJMBTknUeUNmgjg, `window.FlowDS`, cards grouped by these pages); props match its `project/components/index.d.ts`. Private Figma parts (`.Indicator`, `.children`, `.StepperTop`…) live inside their parent — there is no TreeIndicator or TabList component.

Size shorthand for buttons: micro 24 · medium 28 (default) · large 32. Fields: TextField 32 (value `paragraph/small`), Select 36 (value `paragraph/xsmall`; inline label `label/small`, 32px), MultilineField value `paragraph/xsmall`.

## Components
### Button
- **Button** — Text action in four weights: `primary` (near-black `Background-Inverse`, one per view), `secondary` (white with a `Stroke-default` ring, the default), `tertiary` (ghost, fills `Background-Light` on hover) and `plain` (link text in `TextIcons-LinkPrimary`). `tone="critical"` for destructive actions (primary fills `Semantic-critical-primary`); `tone="success"` for approve/confirm (primary fills `Semantic-success-light`). Sizes: `micro` 24px, `medium` 28px (default), `large` 32px. Label is `label-xsmall` (12/16 SemiBold); radius `radius-md`. States follow Figma: hover and press move one fill step, focus adds `shadow-focus`, `loading` swaps the label for a spinner, `disabled` greys the label to `Neutrals-neutral-20`. Consumer provides: the label (a bare verb — "Run analysis", "Reset to default"), optional `iconLeft`/`iconRight` (a 16px Flow icon), `onClick`. Figma: Components › Button `1712:13271`. The Figma description only reads "test"; these notes come from its variants.
- **IconButton** — Square icon-only action in the same four variants and tones as Button; use it for toolbars, row actions and panel headers. Sizes: `micro` 24px (2px padding, 16px glyph), `medium` 28px (default), `large` 32px — all `radius-md`. Keep the glyph optically centred on both axes in every size and state. On a dark or inverse background, bind the glyph to `TextIcons/InversePrimary`; use `TextIcons/InverseDisabled` for a disabled dark state. Never create apparent white by placing a white shape behind the icon. `label` is required: it becomes `aria-label` and the native tooltip. `selected` marks a toggled tool (`Background-Medium`, `aria-pressed`). `icon` takes a Flow icon name or a node; missing glyphs → Tabler outline icon flagged "NEW ICON". Figma: Components › Icon Button `1712:12895`.
- **IconButtonGroup** — Floating white cluster of icon buttons for canvas toolbars (drawing tools, zoom). Children are `IconButton`s — use `tertiary` for idle tools and `selected` for the active one. `direction="vertical"` for side-docked stacks. Padding and gap `spacing-4`, `Stroke-default` ring, `Shadow-sm`. Give `label` — it names the `role="toolbar"`. Figma: Components › Icon Button Group `1726:13819`.
### Input
- **Checkbox** — Checkbox for multi-select options and layer visibility. `variant="default"`: 16px box, `radius-sm`. `variant="icon"`: the eye glyph — unchecked = eye open, indeterminate = dotted eye, checked = eye closed (Figma `style=icon`). Label is `label-xsmall` in `TextIcons-Primary`; row height 24px, gap `spacing-8`. `checked`, `indeterminate`, `disabled`, `onChange`; `label={false}` needs `ariaLabel`. Figma: Components › Checkbox `1747:17310` (eye glyphs: `eye` set `1747:17167`).
- **InlineError** — Critical message under a field: info icon plus `paragraph-xsmall` in `TextIcons-CriticalPrimary`. `tone="alert"` swaps to `alert-triangle` and `TextIcons-CautionSecondary` (the field's alert state). TextField / Select render it automatically when `state="error"` and `helpText` is set. Say what's valid, not what went wrong: "Enter a value between 0 and 100 %". Figma: Components › .Inline error `2182:28565`.
- **MultilineField** — Multi-line text input for notes and descriptions, sharing TextField's label, help and state treatment. Text is `paragraph-xsmall` (12/16, the same size as the label); padding 6×12. `maxLength` shows a counter bottom-right. States: rest, hover, focus, error, disabled, read only — same as TextField. Figma: Components › Multiline field `1712:18123`.
- **NumberStepper** — Up/down half-buttons that sit inside a numeric TextField (`stepper` prop) to nudge a value. Use through `TextField stepper onIncrement onDecrement`; stand-alone only in custom fields. Figma: Components › Stepper `1712:18226` (.StepperTop / .StepperBottom).
- **Select** — Single-choice dropdown field — 36px trigger with a chevron that opens an ActionList of options. `options` are strings or `{value,label}`; `value` + `onChange` controlled. Empty shows `placeholder` ("Select") in `TextIcons-Placeholder`. `labelPosition`: `default` (above), `inline` (label left in `label-small`, 32px control) or `hidden` (still give `label` for screen readers). `leading` takes an icon — the Figma variant with the up–down chevrons uses the `arrow-up-down` icon. Escape closes the menu. Value and unit text are `paragraph-xsmall` (12/16, the same size as the label). Figma: Components › Select `1712:16524` (both variants imported).
- **TextField** — Labelled single-line input, 32px tall, with optional unit, prefix/suffix icon and help text. States from Figma: `placeholder`, `rest`, `hover`, `active`, `focus`, `disabled`, `read only`, `error` (`Background-Critical` + `Stroke-critical`, value in `TextIcons-CriticalPrimary`), `alert` (`Background-Caution` + `Semantic-caution-primary` ring, value and message in `TextIcons-CautionSecondary` with an `alert-triangle` — 2.1:1, flag it). Label: `label-xsmall`; value: `paragraph-small` in `TextIcons-Primary`; unit in `Neutrals-neutral-30` (2.0:1 — keep the unit also readable from the label). Help text is a provenance fragment ("from Archetype default") or, in error/alert, what's wrong and how to fix it. Consumer provides: `label`, `value`/`defaultValue` + `onChange`, `unit`, `helpText`, `state` when forcing one. Figma: Components › Text field `1712:18047` (also Stepper, Inline error). Stepper halves and Clear button aren't built here yet.
- **Toggle** — On/off switch for settings that apply immediately (layer visibility, display options). 36×21 track: off `Neutrals-neutral-10`, on `Neutrals-neutral-120`; 18px white handle. Use Checkbox instead when the choice is submitted with a form. Figma: Components › Toggle `1746:16581`.
### Tab
- **Tab** — 28px pill tab for switching views inside a panel or header. Label `label-small` in `TextIcons-Emphasis`; padding 6×12; `radius-md`. Hover `Background-Light`, selected `Background-Medium`, disabled `Neutrals-neutral-30`. Put a row of tabs in an element with `role="tablist"` (there is no TabList component in Figma). Figma: Components › Tab `2183:34942`.
- **UnderlineTab** — Dense sub-navigation inside a panel, with a 2px underline on the active tab. `header-xxsmall`, padding 8×0, tabs 24px apart. Inactive `Neutrals-neutral-20`, hover `TextIcons-Primary`, active `TextIcons-Emphasis` + underline. Inactive ink is a very light grey (1.6:1) — flag where it has to be read. Figma: Components › UnderlineTab `4757:125080`.
### Segmented Control
- **SegmentedControl** — Two to four mutually exclusive options in a `Background-Light` track; the selected one reads as a white secondary button. Track: padding `spacing-4`, `Stroke-default` ring, `Shadow-sm`, `radius-md`. Options 32px (padding 8×12), `label-xsmall`, optional 16px icon. `options` strings or `{value,label,icon,ariaLabel}`; use for view modes (Massing / Floor plan), not navigation. Figma: Components › Segmented Control `2736:30399`.
### Headers
- **FullScreenModalHeader** — 56px title bar for full-screen editors and analysis views. `type=Default`: `title` (`header-medium`) + primary action + close. `type=back`: adds `onBack`. `type=Analysis`: `leading` (an inline Select + "Add to Comparison") and a Close button; pass `title=""`. Bottom border `Stroke-default`; padding 0×16, gap 16. Figma: Components › Headers › Full Screen Modal `2183:35074`.
- **PageHeader** — Page title bar (padding 16×24) with a leading marker, title, optional description and right-aligned primary actions. Figma `type=archetype`: `leading` = ColorIndicator, `title` in `header-medium`. `type=user`: `leading` = AvatarsStacked + a micro switcher IconButton, no title. `description` is `paragraph-small` in `Neutrals-neutral-90`; `badge`, `onBack` optional. Figma: Components › Headers › Page `2183:35091`.
### Action List
- **ActionList** — Menu surface for commands and option lists — white, `radius-md`, `Stroke-subtle` ring, `Shadow-md`. Compose `ActionSection` (label-xsmall heading) and `ActionItem` rows (28px, `paragraph-xsmall`, optional 16px `icon`, `help`, `trailing`). Item hover `Background-Light`, pressed/selected `Background-Medium`; `destructive` uses critical text and `Background-Critical` hover. `role="listbox"` + items `role="option"` when used as a Select menu. Figma: Components › Action List `1748:30958`, .Action-Item `1748:30167`, .Action-Section `1748:30241`.
### Toast
- **Toast** — Transient confirmation in a dark pill; auto-dismisses after 4s. `type`: default (`Background-Inverse`) or `critical` (`Semantic-critical-primary`, `role=alert`). 44px tall, padding 12 left and right, gap 8, `radius-md`, `Shadow-md`; text `label-xsmall`. `action` as a string renders a white text button (`onAction`); `onDismiss` adds the close button and auto-dismiss; `persist` keeps it. Figma: Components › Toast `1897:24371`.
### Tooltip
- **Tooltip** — Short label on hover or focus — `Background-Inverse`, `label-small`, with a tail. Wrap one focusable child; `content` is a few words. `position`: above (default), below, left, right. Never put essential information only in a tooltip. Figma: Components › Tooltip `1627:22026`.
### Color Indicator
- **ColorIndicator** — Colour swatch keying a series, zone or category to a `Misc-*` colour. `size`: medium 14px `radius-sm`, small 8px 2px radius. Always next to a text label. Misc colours never signal status. Figma: Components › Color Indicator `1748:18668`.
### Avatar Stacked
- **AvatarsStacked** — Row of 20px avatars for collaborators, `+N` after `max`. Each avatar has a 1px `Background-Default` ring and overlaps its neighbour by 1px; initials `label-xsmall`, white on `Misc-*` (yellow takes `TextIcons-Emphasis`). `Avatar` is exported alone: sizes L 28 · M 24 · S 20 · XS 18 (Figma ↪ Comments `.Avatar`). Figma: Components › AvatarsStacked `1748:19238`.
### Badge
- **Badge** — Small status or count label. `type`: default (`Background-Medium` + `TextIcons-Primary`), info (`Background-Info` + `TextIcons-LinkSecondary`), critical (`Semantic-critical-primary` fill, white text). `shape`: `label` (`radius-md`, 2×8) or `number` / `smallNumber` (pills, 2×4). Optional 14px `icon`. Text `label-xsmall`. Figma: Components › Badge `1713:13268`.
### Modal
- **Modal** — Dialog card — grey title bar, content slot, right-aligned footer — shown over a Dimmer. 620px wide, `radius-lg`, `Stroke-default` ring, `Shadow-md`. Title `header-small` on `Background-Light`. Footer: secondary then primary Button. Figma `Size=Critical`: the slot holds an in-card critical Banner and the primary uses `tone="critical"`. `inline` renders the card alone; otherwise it sits in a Dimmer. Figma: Components › Modal `1748:32540` (slot `.Slot` `6036:2844`).
### Dimmer
- **Dimmer** — Full-viewport `Background-Overlay` scrim that holds a Modal and blocks the page behind it. Clicking the scrim (not the modal) calls `onClick` — usually the modal's close. Figma: Components › Dimmer `4901:148903` (1440×1024 with a large Modal centred).
### Banner
- **Banner** — Inline message — for context, success, warnings and failures. Default: white card, `Stroke-default` ring, `Shadow-xs`, `radius-lg`, a tinted 28px icon tile and one line of `header-xsmall` text; optional dismiss. `inCard`: tone background (`Background-Info` / `-Success` / `-Caution` / `-Critical`), `radius-md`, padding 8; icon + `title` (`header-xsmall`) and a `paragraph-small` description, all in the tone's text colour. Warning in-card text is `Semantic-caution-primary` (2.1:1 on its ground) — flag it where the text matters. Figma: Components › Banner `1748:32763`.
### ChipFilter
- **ChipFilter** — Pill toggle for filtering a list. Unselected: white + `Stroke-default` ring; pressed `Neutrals-neutral-10`. Selected: `Background-Inverse`; pressed `Neutrals-neutral-80`. Text `label-xsmall` in `TextIcons-Emphasis` (inverse when selected); padding 6×12; optional 14px icon. Figma: Components › ChipFilter `3722:60657`.
### DropdownPill
- **DropdownPill** — Compact pill that sets a category inline in a row. Rest: white + `Stroke-subtle`; hover/open: `Background-Light` + `Stroke-default`. Text `label-xsmall`: `TextIcons-Emphasis`, or `Neutrals-neutral-30` "Unclassified" when empty. Figma: Components › DropdownPill `4705:118212`.
### Scroll Indicator
- **ScrollIndicator** — 5px overlay scroll thumb. `tone="light"` (`Background-Light`, for dark grounds) or `"dark"` (`Background-Inverse`, for light grounds); 8px from the edge. Figma: Components › Scroll Indicator `4837:121441`.

## Shell (page `6077:605` — shared app chrome, every product)
- **AppShell** — The frame every product screen starts from. Variant `Product` = Urbanflow | Flux; booleans `Show left panel`, `Show right panel`; native slots `Canvas` (full-bleed, behind), `Left panel`, `Canvas tools`, `Right panel`. Body padding and gap `spacing/8`; panels hug width and fill height. Design frame 1440×1024. Code: `AppShell` + `AppShellPin` (top-right / bottom-center / bottom-right). Figma: Shell › AppShell `6085:5003`.
- **TopNavigation** (`.TopNavigation`) — 44px bar, `Background/Inverse-Secondary`: product logo (white Urbanflow or Flux mark, 16px) + UrbanflowTopNav. `Product` = Urbanflow | Flux; Flux hides notifications and collaborators. Product modes never go here. Figma: `6080:9700`.
- **UrbanflowTopNav** (formerly ProposalBanner) — the project bar: project switcher (menu: Show version history · Create proposal · View proposals · Rename project · Project: Return to home · Delete project), open proposal (muted project name + ProposalTitle; proposal menu: This proposal — Review and merge changes · Update from main · Archive proposal · Rename proposal · Delete proposal; Other proposals — View main · View proposals · Create proposal; Project — Return to home), notifications, AvatarsStacked, credits chip (`Background/Card`, DM Mono). Variants Main · Opened · Proposal · Proposal Opened. Figma: `6080:5152`.
- **UtilitiesToolbar** — floating rail top-right of the canvas: vertical Icon Button Groups (gap 8) of large secondary IconButtons; active = `State=active`. `Product` = Urbanflow (analytics, lightbulb, coin, 2 custom tools flagged NEW ICON · ai, photo, construction) | Flux (modes: Model `massing`, HVAC `hvac`, Weather `cloud`, Runs `run`, Results `analytics`, Files `files`; one active). Figma: `6087:5091`.
- **LeftContextPanel** — The AppShell's left panel. `Product` = Urbanflow (**252px**: page switcher header — menu Properties, Archetypes, Assemblies, EPW, Policies — collapse button, tabs, Building / Floor / Zone sections; `Menu` = Closed | Open) | Flux (**360px**: one `Panel content` slot for the chat — conversation, steps, composer). **Width: fixed at the product default every time a user opens the app or starts a web session; the user can resize it during the session by dragging the right edge (code: 240–480px, arrow keys, double-click resets). Never save the width.** Code: `LeftContextPanel product="urbanflow"|"flux"`, `defaultWidth`, `minWidth`, `maxWidth`, `resizable`, `onWidthChange`. Figma: `6080:8973`.
- **ProposalTitle** / **ProposalBadge** (Shell primitives) — proposal name + status on the dark top bar. Statuses Draft · Behind main · In review · Changes suggested · Ready for merge · Merged · Closed (shows "Archived"). Figma binds fills to `Background-new (ignore)` — in code and notes use `Background/Card`, `-Caution` (text `Semantic/caution-heavy`), `-Critical`, `-Info`, `-Success`; flag the drift. Figma: `6080:5359`, `6080:5123`.
- **.Slot** — dashed placeholder for an unbuilt slot's contents (e.g. Flux chat / model panel). Never ship with one visible.
