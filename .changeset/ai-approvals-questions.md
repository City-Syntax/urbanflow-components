AI cards for when the agent needs the user: approvals, questions, a waiting banner and a message queue. No Figma frames exist for these yet. They follow Flux's cards, restyled with Flow tokens, and design will review them. Every card is presentational: pass in data and callbacks, and your app keeps the gate, the timeout and the queue. Install with `npx shadcn add @urbanflow/<name>`:

- `ai-approval-card`: `AIApprovalCard` asks before the agent changes something. It takes `title`, an optional `detail`, an optional body as children and `actions`. `actions` is an ordered list of `{ id, label, variant, tone?, title?, onSelect }`, so each app picks its own buttons. The core app passes Approve and Deny. Flux passes Allow once, Allow <tool> in this project, Full auto and Deny. The buttons sit in a grid that stacks them in a narrow panel, and long labels wrap. Set `status` to `decided`, `denied` or `stopped` once the request is answered, and the card shrinks to a one-line record. Pass `outcome` to change its wording, and set `auto` on a decided card to show the Auto badge. `AIApprovalDiff` draws one file's unified diff to use as the body.
- `ai-question-card`: `AIQuestionCard` shows the agent's questions inline. Each question is `{ id, prompt, kind: "single" | "multi" | "text" | "number", options?: { value, label, description? }[], recommended?, allowOther?, placeholder? }`. The recommended answer starts selected and is marked "Recommended". `onSubmit({ answers, skipped })` stays disabled until something is answered. Enter in a field, or Ctrl/Cmd+Enter anywhere in the card, submits. Skip appears when you pass `onSkip`. `status="timed-out"` keeps the form open under a note, which you can change with `note`. `status="answered"` lists each answer from `answers`. The core app's ask_user maps to one question: `{ id, prompt: question, kind: "single", options: options.map((o) => ({ value: o, label: o })), allowOther: true }`.
- `ai-pending-banner`: `AIPendingBanner` is the sticky "Waiting for you" bar above the composer. Pass what is waiting as children and a `count`. A count above 1 shows a badge, and a count of 0 renders nothing. `onJump` runs when the user presses Show; scroll to the card and focus it there.
- `ai-message-queue`: `AIMessageQueue` lists messages typed while the agent works. `items` is `{ id, text, editable? }[]`. The header reads "N queued", with an optional `note` such as "sent when the agent is free", and it collapses the list. Each row can move up and down (`onReorder` gets the new id order) and be edited, sent now or removed (`onEdit`, `onSendNow`, `onRemove`). A control appears only when you pass its callback.

Each has `meta.version` `1.0.0`.
